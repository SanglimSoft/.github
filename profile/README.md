# SanglimSoft

**SanglimSoft**는 일상에 도움이 되는 여러 개인 프로덕트를 만들고 운영하는 개발 스튜디오입니다. 정부지원사업 알림부터 AI 상담, 사진 편집, 개발자 도구까지 서로 다른 영역의 서비스를 하나씩 쌓아가고 있습니다.
